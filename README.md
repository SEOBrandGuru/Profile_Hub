## About

ProfileHub is a platform for building clean, fast-loading digital profile pages for brands. Each profile is fully standalone — no dependencies, no backend, no tracking. Pure HTML and CSS, deployable anywhere in seconds.

Profiles are designed to reflect each brand's identity individually — unique typography, colour palette, and layout per brand.

- HTML5 · CSS3 · Vanilla JS
- Google Fonts
- Zero backend · Zero frameworks · Zero build step
